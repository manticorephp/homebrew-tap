# manticorephp/homebrew-tap

```bash
brew install manticorephp/tap/manticore
```

macOS arm64 (15+). The formula installs the published build of [Manticore](https://github.com/manticorephp/compiler) with `openssl@4`, `pcre2`, `icu4c` and `pkgconf`. The compiler release workflow updates it on every tag. Linux: use `install.sh` or the container image.
